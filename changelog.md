# Changelog

v1.1: Added Quick QR for one-tap display of the last-used wallet's QR. NFC tag export now lets you choose the tag type (NTAG213, NTAG215, or NTAG216), with correct capability-container size, chip-specific Mifare version byte, computed BCC bytes, and default factory config pages per type. Files are saved as `[wallet]_[ntagtype].nfc`. All Unbank branding, splash screen, Download Unbank QR, and About screen unchanged.

v1.0: Initial release. Multi-wallet support for Speed, Strike, and Wallet of Satoshi. On-device username editor with built-in keyboard. Persistent storage of usernames on SD card. Equal-sized QR rendering. Manual QR refresh. Haptic feedback on QR display. NFC tag file export for writing NTAG213 stickers. Splash screen on launch. Download Unbank QR. About screen.
