# NFC Tools

NFC Tools can read and write your NFC tags.

## Read features
- Automatic protocol detection and chip identification (UID, SAK, ATQA)
- NDEF record reading and display
- Scrollable record list with per-record detail view
- QR Code display for any compatible record
- Memory dump (sectors / pages analysis)
- Detailed chip info (version, free memory, block count)

## Write features
- Text
- URL / Custom URI
- Unit.Link
- Mail
- Contact
- Phone / SMS
- Facetime + Facetime Audio
- Social Networks
- Search engines
- Location
- Bitcoin
- Wi-Fi
- Bluetooth
- Custom Data

## Other features
- Erase Tag: Clears the NDEF content from the tag
- Lock Tag: Permanently locks the tag as read-only (NTAG21x)
- Format Memory: Write 0x00 on tag memory (NTAG, ICODE SLI/X, Mifare Classic 1K+4K)
- Read Memory: Full memory dump with ASCII view
- Set or remove Password: Password protection for NTAG21x
- NFC Commands: Send raw APDU commands

## Supported chips
- NTAG: NTAG203, 210, 212, 213, 213 TT, 215, 216
- MF Ultralight: Ultralight, Ultralight C, Ultralight EV1
- Mifare Classic: 1K, 4K
- ICODE: SLI, SLIX, SLIX2, SLIX-S, SLIX-L
- DESFire EV1, EV2, EV3 (NDEF)
- FeliCa: Sony FeliCa
- ISO 14443-3A: Generic tags
