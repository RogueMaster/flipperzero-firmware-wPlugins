# Stratagame Hero

This is a game application for Flipper Zero made after arcade game with the same name inside Helldivers 2 video game.

It features:

* original game where you need to enter stratagem codes
* a quiz game where you need to guess which stratagem given code is for
* a catalog of all Helldivers 2 stratagems
