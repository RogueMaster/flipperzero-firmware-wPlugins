v0.1:
- Initial public release
- Seven root keys (C, D, E, F, G, A, B)
- A few intermediate chord variations: Major, Minor, Major 7
- Intuitive D-pad navigation (Left/Right for key, Up/Down or OK for variation)
- Clean, readable portrait mode UI showing large chord name and visual fingering diagram
- Starts on C Major by default
- Built with Flipper Zero SDK for native performance and low power usage

Future plans:
- More advanced chords (9ths, 11ths, etc.)
