v1.0:
Initial release.
- Engagement sessions with client/location metadata, saved to SD card.
- Safe file naming, rename cleanup, overwrite and unsaved-changes prompts.
- Assets (door, RFID reader, camera, BLE, RF, unknown) with type, risk, notes,
  finding severity and remediation.
- Evidence linking with a native file browser and metadata extraction from
  .sub (frequency/preset) and .nfc (device type/UID), plus quick capture import.
- Directed relationship graph with labelled nodes, directional arrows,
  riskiest-attack-path highlighting and floorplan node placement.
- Risk propagation along access/control edges and a risk summary dashboard.
- JSON and Markdown export with an executive summary ranked by severity.
- Optional PIN screen lock.
