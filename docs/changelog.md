# Changelog

## 1.0 - 2026-10-06

Initial public release.

### Added

- Tamagotchi Connection 2024 infrared communication
- Visit mode
- Configurable character, name and gender
- Persistent profile settings
- Points game
- Configurable GP wager
- Selectable win, loss or random game result
- Gift mode
- Food gifts (IDs 0-35)
- Snack gifts (IDs 36-77)
- Item gifts (IDs 78-131)
- Special gift effects (IDs 132-141)
- Random Gift
- Random Food
- Random Snack
- Random Item
- Random Special

### Tested

Visit, Points Game and Gift communication have been physically tested with
a Tamagotchi Connection 2024 re-release.

### Planned

- Additional game modes
- Marriage support
