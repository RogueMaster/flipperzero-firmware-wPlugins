Flipper Recon is a physical security reconnaissance notebook for authorized
security assessments. It is not an attack tool — it helps you collect, organize
and analyze observations from physical security audits.

## What it does

- **Engagements**: create audit sessions with client and location metadata,
  stored on the SD card.
- **Assets**: record doors, RFID readers, cameras, BLE devices, RF devices and
  unknown devices, each with a type, risk score and notes.
- **Evidence**: attach notes and link capture files (RF, NFC, BLE) to assets.
- **Relationship graph**: model directed relations between assets
  (Badge to Reader to Door to Camera) and view them as a node graph. Risk
  propagates along access and control edges.
- **Exports**: generate JSON and Markdown reports on the SD card.

## Responsible use

Intended solely for authorized security assessments and educational use. Only
assess systems you own or have explicit written permission to test.
