本次更新加入小节线和按小节跳转，并将 By Bars 设为默认跳转方式。感谢 [Issue #1](https://github.com/ZeroNinx/flipper-zero-taiko-player/issues/1) 提出的建议。

## 更新内容

- 谱面轨道新增一像素宽的白色小节线，绘制在音符后方，支持 `#BARLINEON` / `#BARLINEOFF`，小节线按起点 BPM 与 HS 移动。
- 菜单新增 **Seek Mode → By Bars / By Time**。默认 By Bars，左右键每次跳转 1 小节；前后可分别设置为 1 / 3 / 5 / 10 小节，原有按时间跳转仍可选择。
- 按所选难度的实际小节起点跳转，支持 BPM 变化、拍号变化、OFFSET、非负 DELAY 和空小节；隐藏小节线不影响跳转目标。
- 小节中间按后退先回到当前小节开头，恰好在小节线上则返回上一小节；前进到下一小节。暂停时也可跳转，超出范围时限制在音频起止位置。
- 分别保存小节间隔、秒数间隔与跳转方式。新安装、旧配置缺少 SeekMode 或恢复默认设置时使用 By Bars；已明确保存的 By Time 选择继续保留。
- 增加小节时间、隐藏／空小节、跳转边界、小节线裁剪、设置和内存分配失败的测试。作者已在 Momentum CN v1.1.6 设备上确认小节线与跳转功能正常。

## 安装包

| 安装包 | 固件 SDK | API |
| --- | --- | --- |
| `taiko-player-v0.5.1-official.zip` | 官方 1.5.1 | 88.2 |
| `taiko-player-v0.5.1-momentum.zip` | Momentum mntm-009 | 79.2 |
| `taiko-player-v0.5.1-momentum-012.zip` | Momentum mntm-012，适用于已验证的 Momentum CN v1.1.6 | 87.1 |

请选择与设备兼容的安装包，将包内 `sdcard/` 覆盖到 SD 卡根目录。包内包含应用、鼓声、许可文件、转换脚本和中英文说明，不包含歌曲或用户设置。升级时保留自己的歌曲和 `settings.ff`。

FAP 版本头只支持两段版本号，因此本次应用的头版本仍显示为 0.5；发布版本为 0.5.1，包内 `BUILD.json` 同时记录两者及源码提交。

## English summary

Add scrolling measure lines and **Seek Mode → By Bars / By Time**, following the suggestion in [#1](https://github.com/ZeroNinx/flipper-zero-taiko-player/issues/1). Bar seeking is now the default, with one bar per direction and independently configurable 1 / 3 / 5 / 10 bar intervals. Existing saved mode preferences are preserved. See the [English README](../../README.en.md#controls) for controls and setup.
