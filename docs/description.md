IR Pad is a customizable, portrait IR remote for the Flipper Zero. Hold the
Flipper upright and use it like a real remote.

Features
- Vertical layout with long (full width) and short (half width) buttons.
- Multiple remotes, each with its own layout; pages with a dot indicator.
- Each button shows an icon, or text when it has no icon.
- Transmits parsed and raw signals loaded from your saved infrared files.
- On-device editor: assign an IR signal (file browser then signal picker),
  set the text, pick an icon from a grid, change the size, move, add and delete.
- Works with Fav Launcher: infrared favorites open here directly.
- Original 16px icon set.

Controls
- OK transmits the focused button.
- Up/Down move within the page. Left/Right switch the two buttons in a row,
  or flip pages at the edge.
- Long-press OK edits the focused button.
- Back returns to the remote list, or exits when opened from a favorite.
