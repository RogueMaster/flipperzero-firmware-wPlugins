Fav Launcher is a 2x5 icon-grid launcher for your Flipper favorites. It reads
the favorites you already pinned and shows them as a grid of assignable icons.

Features
- Reads your favorites list automatically.
- Assign an icon to each favorite from an on-device picker.
- Wrap-around navigation; remembers the last selection.
- Opens the favorite in its own app, then returns to the grid.
- Infrared favorites open in IR Pad when installed, else the stock Infrared app.

Controls
- Arrows move, OK launches, Back exits.
- Long-press OK picks an icon for the focused favorite.
