# TamaConnect

TamaConnect lets your Flipper Zero communicate with Tamagotchi Connection 2024 devices using infrared.

Use your Flipper as a virtual Tamagotchi for supported Connection activities.

## Features

- Visit a real Tamagotchi
- Choose the virtual Tamagotchi character
- Set its name and gender
- Play the Points Game
- Choose a GP wager
- Choose win, lose, or random game results
- Send food, snacks, and items
- Send special gift effects
- Send random gifts
- Save profile settings between sessions

## Compatibility

TamaConnect has been physically tested with the Tamagotchi Connection 2024 re-release.

No additional hardware is required. Communication uses the built-in infrared transceiver of the Flipper Zero.

## Gift mode

Select a gift in TamaConnect.

On the Tamagotchi, open Connect, select Present, wait for STAND BY, and press the middle button to start the connection.

Point the Tamagotchi and Flipper Zero infrared ports toward each other during communication.
