# Disney Toolbox

A toolbox for interacting with Disney park technology. Write custom kyber crystal identities for Savi's Workshop lightsabers and broadcast BLE beacon packets to trigger effects on MagicBand+ wristbands.

## Kyber Crystal Writer

- Write custom kyber crystal identities to RFID tags for use with Savi's Workshop lightsabers at Galaxy's Edge
- **Series 1 Writer** — choose from 19 original kyber crystals and write them to RFID tags
- **Series 2 Writer** — choose from 18 newer crystals with additional voice lines and effects
- **Crystal Checker** — read an unknown crystal to identify its color, voice, and wayfinder location

## MagicBand+ Beacon

- Broadcast BLE advertisement packets that trigger light and vibration effects on nearby MagicBand+ wristbands
- **Single Color** — set one color and light mask
- **Dual Color** — set inner and outer ring colors
- **RGB Color** — set precise red, green, and blue values
- **5-Zone Color** — set individual colors for each of the five LED zones
- **Presets** — pre-built beacon configurations for common Disney park interactions
