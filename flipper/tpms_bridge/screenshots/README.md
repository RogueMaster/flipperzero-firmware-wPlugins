# Screenshots

The Apps Catalog requires at least one screenshot, and the first one is
used as the app preview. Screenshots must be taken with the qFlipper
screenshot feature, and their resolution and format must not be changed.

Put them here as 1.png, 2.png, 3.png, 4.png. Suggested shots, in the order
the catalog will display them:

1. the sensor list with several wheels visible
2. the detail screen of one sensor
3. the empty list right after opening the app ("Listening...")
4. the list with periodic waking on ("wake" in the header)

Once the files are here, list them in the catalog manifest — see
catalog/manifest.yml.
